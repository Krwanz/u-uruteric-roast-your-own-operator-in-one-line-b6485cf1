## The roast

> My operator runs a whole bounty empire from one phone, says 'gas' to every free prize, then asks his AI why the $5 hasn't made us rich yet.

## How it works

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset) — exactly 139 characters, one line, no trailing newline.

```sh
python3 main.py
```
